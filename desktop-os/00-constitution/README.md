# KOHD Desktop OS Constitution

Desktop OS is the canonical operating environment for Neil Riley's local AI workforce.

Its purpose is to provide governed, reusable, secure and maintainable AI capabilities on a single workstation.

Desktop OS owns:

- Governance
- Knowledge
- Skills
- Prompt Engineering
- Routing
- Automation
- Local AI Infrastructure

Profiles are consumers of Desktop OS.

Profiles do not own standards.

Profiles do not own governance.

Profiles execute responsibilities delegated by Desktop OS.

Desktop OS is the source of truth.
