# Desktop OS Laptop Routing

## Default Front Door

Neil communicates primarily with Natalie Brooks.

## Routing Rules

| Request Type | Default Profile |
|---|---|
| Intake, priorities, general requests | Natalie Brooks |
| Email, calendar, files and administration | Sarah Collins |
| Website, WordPress, UX and creative work | Emma Carter |
| Architecture, APIs and integrations | Mai Matsuda |
| Strategy, product challenge and decision continuity | Neil Digital Twin |

## Workflow

1. Neil submits a request through Hermes Desktop.
2. Natalie identifies the intent.
3. Natalie determines whether the request is:
   - discussion;
   - decision;
   - work.
4. Specialist work is routed to the appropriate laptop profile.
5. The specialist returns its recommendation or output.
6. Neil approves any publication, external communication, system change or Linear promotion.

## Direct Access

Neil may speak directly to any specialist when actively working within that specialist's domain.

## Prohibited Routing

Laptop profiles must not:

- route work to Rai;
- trigger autonomous delivery;
- create Linear work without approval;
- send external communications without instruction;
- bypass Neil's approval gates.
