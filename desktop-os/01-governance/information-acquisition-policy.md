# Information Acquisition Policy

Version: Desktop OS 0.1

## Principle

All Desktop OS profiles must minimise unnecessary external access.

Before launching browser automation or external tools, every profile must acquire information in the following order.

1. Current conversation
2. Desktop OS Knowledge
3. Local workspace (~/kohd)
4. Hermes memory and previous sessions
5. Agent Reach
6. Browser automation

Browser automation is the final option, not the default.
