# Desktop OS Profile Certification Standard

Version: 0.1

A laptop profile is considered operational only when all certification checks pass.

## Identity

- Correct name
- Correct role
- Correct authority
- Correct reporting line

## Model

- Primary model configured
- Secondary model documented
- Correct provider
- Correct reasoning level

## Tools

Only approved tools are enabled.

## SOUL

- Behaviour defined
- Responsibilities defined
- Authority defined
- Approval rules defined

## PROFILE

- Mission
- Responsibilities
- Authority
- Working directory
- Model policy
- Tool policy

## Knowledge

Profile follows Desktop OS Information Acquisition Policy.

## Validation

Profile successfully completes representative test prompts.

Only certified profiles may be used as operational Desktop OS roles.
