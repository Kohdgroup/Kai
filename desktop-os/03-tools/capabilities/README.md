# Desktop OS Capability Registry

Capabilities are reusable functions provided by Desktop OS.

Profiles consume capabilities. Profiles do not own the underlying standards, tools or governance.

## Capability Standard

Every capability must define:

- purpose;
- default owner;
- responsibilities;
- inputs and outputs where applicable;
- required tools;
- primary and fallback models;
- dependencies;
- approval requirements;
- prohibited actions.
