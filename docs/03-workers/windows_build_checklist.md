# Windows PC Image Render Node Build Checklist

Purpose: build a primary ComfyUI render node for realistic portraits and campaign assets.

## Hardware
- [ ] NVIDIA GPU installed
- [ ] 16GB VRAM preferred, 12GB minimum
- [ ] 32GB RAM minimum, 64GB recommended
- [ ] 2TB NVMe SSD minimum, 4TB preferred
- [ ] Wired network connected

## Operating system
- [ ] Windows 11 Pro installed and updated
- [ ] Power settings set to never sleep
- [ ] Automatic updates scheduled outside render windows

## Software
- [ ] ComfyUI cloud/local plan decided
- [ ] ComfyUI installed
- [ ] Required custom nodes installed
- [ ] Model storage directory created
- [ ] Hermes client or job receiver installed

## Storage
- [ ] Working directory created
- [ ] Drafts folder created
- [ ] Finals folder created
- [ ] Archive folder created
- [ ] WebDAV target reachable

## Validation
- [ ] Generate a test portrait
- [ ] Generate a test campaign asset
- [ ] Save outputs to WebDAV
- [ ] Confirm Linear link/provenance is written
