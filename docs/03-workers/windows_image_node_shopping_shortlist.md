# KOHD Windows Image Node Shopping Shortlist

## Preferred build
- GPU: NVIDIA RTX 4080 Super 16GB
- CPU: modern 8+ core Intel or AMD CPU
- RAM: 64GB DDR5
- Storage: 2TB NVMe SSD
- OS: Windows 11 Pro
- PSU: quality 850W+ (higher if using a 4090-class card)

## Best value build
- GPU: NVIDIA RTX 4070 Ti Super 16GB
- CPU: modern 8+ core Intel or AMD CPU
- RAM: 64GB DDR5
- Storage: 2TB NVMe SSD
- OS: Windows 11 Pro
- PSU: quality 750W–850W

## Minimum acceptable build
- GPU: NVIDIA RTX 3060 12GB
- CPU: modern 6–8 core Intel or AMD CPU
- RAM: 32GB DDR4/DDR5
- Storage: 1TB NVMe SSD
- OS: Windows 11 Pro
- PSU: quality 650W+

## What matters most
1. GPU VRAM
2. RAM capacity
3. SSD capacity
4. Cooling and PSU quality
