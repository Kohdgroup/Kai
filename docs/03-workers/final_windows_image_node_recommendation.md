# Final KOHD Windows Image Node Recommendation

## Recommended purchase
- GPU: **NVIDIA RTX 4080 Super 16GB**
- RAM: **64GB**
- Storage: **2TB NVMe SSD**
- OS: **Windows 11 Pro**
- CPU: modern 8+ core Intel or AMD CPU
- PSU / cooling: quality parts, sized for the GPU

## Why this is the right choice
- Strong enough for realistic headshots and campaign assets
- Enough headroom for other KOHD jobs at the same time
- Much better long-term fit than a minimum-spec card
- Cheaper and cleaner than jumping straight to a 4090-class build
- Good balance of performance, cost, and longevity

## Expected cost band
- Rough total: **£1,800–£2,400** depending on CPU, case, storage, and board choices

## If you want to spend less
- RTX 4070 Ti Super 16GB + 64GB RAM + 2TB NVMe
- lower cost, still strong, slightly less headroom

## If you want maximum headroom
- RTX 4090 24GB + 64GB–128GB RAM + 4TB NVMe
- best performance, highest cost

## Procurement note
If a verified used RTX 3090 24GB is available at a good price, it may offer the best value-per-pound, but the 4080 Super is the cleanest new-buy recommendation.
