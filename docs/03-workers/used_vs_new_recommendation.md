# Used vs New Recommendation

## Buy used when:
- you want maximum VRAM per pound
- you’re comfortable with careful inspection
- you can test the card before committing
- you want the best value for a 3090/4080-class upgrade path

### Best used target
- RTX 3090 24GB

Why:
- excellent VRAM for ComfyUI
- often very strong value on the used market
- better headroom than a 4070 Ti Super

## Buy new when:
- you want lower risk
- you want warranty/support
- you want a cleaner procurement path
- you prefer predictable long-term reliability

### Best new target
- RTX 4070 Ti Super 16GB or RTX 4080 Super 16GB

Why:
- modern efficiency
- excellent compatibility
- good balance of cost and capability
- easier to source and support

## My recommendation for KOHD
- If you want the best value: buy used RTX 3090 24GB if you can verify it
- If you want the cleanest procurement: buy new RTX 4080 Super 16GB
- If budget is tighter: buy new RTX 4070 Ti Super 16GB
