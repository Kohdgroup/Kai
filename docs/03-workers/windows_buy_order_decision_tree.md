# Windows Image Node Buy-Order Decision Tree

## Step 1: Decide the budget band

### Band A — Budget conscious
Choose this if you want the lowest spend while still getting a workable image node.

Recommended:
- RTX 3060 12GB
- 32GB RAM
- 1TB NVMe
- Windows 11 Pro

Tradeoffs:
- slower batches
- tighter VRAM limits
- less comfortable for future growth

### Band B — Best value
Choose this if you want the best balance of price, performance, and longevity.

Recommended:
- RTX 4070 Ti Super 16GB
- 64GB RAM
- 2TB NVMe
- Windows 11 Pro

Tradeoffs:
- still not the absolute max headroom
- but very strong for KOHD’s current needs

### Band C — Premium / buy-once
Choose this if you want maximum headroom and the least regret over time.

Recommended:
- RTX 4080 Super 16GB or RTX 4090 24GB
- 64GB to 128GB RAM
- 2TB to 4TB NVMe
- Windows 11 Pro

Tradeoffs:
- highest spend
- best long-term headroom
- strongest option if the machine becomes a core production box

## Step 2: Check availability

- If a clean used RTX 3090 24GB is available, it may beat a new midrange card on value.
- If used quality is uncertain, prefer new hardware.
- If you need warranty/support and easy procurement, buy new.

## Step 3: Apply KOHD logic

- If image work is important but not time-critical: prefer value or used-value.
- If this box must also handle other jobs reliably: prefer 64GB RAM.
- If you want to avoid re-buying later: prefer 16GB+ VRAM.

## Recommended order of preference for KOHD
1. Used RTX 3090 24GB if verified in good condition
2. New RTX 4080 Super 16GB
3. New RTX 4070 Ti Super 16GB
4. Budget RTX 3060 12GB only if cost is the overriding concern
