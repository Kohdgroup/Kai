# Founder KPI List

## Executive KPI set (v1)
1. Active work items
2. Active sprints
3. Work in hand
4. Estimated remaining cost
5. Estimated remaining tokens
6. Portfolio value / business impact
7. Blockers / risks
8. Change-control readiness
9. Worker count (current total: 18)
10. Worker distribution by role/team
11. Open issues vs completed issues
12. Planned vs active work balance

## Recommendations
- Show the top 8 on the main founder dashboard.
- Keep worker count and worker distribution in the same executive layer.
- Use drill-down panels for team/project detail.
- Avoid issue-level detail unless the viewer is an operator.
