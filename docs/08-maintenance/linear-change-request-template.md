# Linear Change Request Template

Source of truth: RELGOV-10

## Required fields
- Title
- Change type
- Risk level
- Blast radius
- Services impacted
- Owner
- Approver
- Change window
- Dependencies
- Rollback plan
- Validation plan
- Affected people / recipients
- Slack approval status
- Linear issue link

## Definition of complete
A change request is complete only when the mandatory fields are filled, dependencies are known, rollback is ready, and the approval route is explicit.
